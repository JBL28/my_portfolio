# 이 포트폴리오가 작성된 과정입니다.

이 포트폴리오는 생성형 AI를 활용해 작성되었습니다.

단순히 내용을 생성하게 한 것이 아니라, 조사부터 재료 발굴, 작문, 검증까지 전 과정에 AI를 활용했습니다.
관심 있는 분들을 위해 실제 작업 과정을 간단히 정리했습니다.


## 프로젝트 내용 구성

1. 레퍼런스 조사

   * 실제 개발자 포트폴리오가 어떻게 작성되어 있는지 조사했습니다.
   * 무작정 조사를 시키는 대신, 무엇을 알고 싶은지 먼저 기준을 세우고 그에 맞춰 조사하도록 했습니다.

2. 재료 발굴

   * 제가 직접 노션에 작성해둔 초안을 바탕으로, AI가 상담하듯 질문하며 포트폴리오에 활용할 재료를 발굴하도록 했습니다.
   * 작문 중 근거가 부족한 부분이 생기면 다시 질문을 통해 실제 경험을 추가로 발굴했습니다.
   * AI가 없는 경험을 만들어내지 않도록, 직접 확인할 수 있는 내용만 재료로 사용했습니다.

3. 작문 전략 수립

   * 재료를 모은 뒤 바로 작문을 시키지는 않았습니다.
   * 실제 작문 순서와 레퍼런스를 참고해 개요와 작문 전략을 먼저 수립했습니다.
   * 이를 바탕으로 초안을 작성하고 반복해서 다듬었습니다.

4. 검증 및 퇴고

   * 작성된 내용은 원본 자료와 다시 대조했습니다.
   * 근거가 부족한 수치나 과장된 표현, 반복되는 내용은 제거했습니다.
   * 외부 피드백을 반영하며 주장과 표현을 반복해서 수정했습니다.

5.  윤문 플러그인 적용

   * 포트폴리오는 AI가 아닌, 사람이 읽는 글입니다.
   * AI를 활용해 생성한 글 특유의 말투는 가독성이 낮습니다.
   * 따라서, 자연스러운 한국어 어투로 글을 개선해주는 플러그인을 활용해 읽기 쉬운 글로 최종 개선하였습니다.


## 프로젝트 기획_설계

1. 요구사항 정리

   * 구현하고자 하는 내용을 의도와 함께 명확하게 적어 구체화하였습니다.
   * 직접 작성한 요구사항을 바탕으로 프로젝트 설계를 합니다.
      * AI가 설계한 내용을 리뷰하고, 다른 모델로 다시한번 피드백합니다.
   * 설계를 바탕으로 단계별 구현 계획을 세웁니다.
   * 단계별로 직접 검증하며 완성도를 높입니다.
