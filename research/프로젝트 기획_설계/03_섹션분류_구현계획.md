# 프로젝트 상세 섹션 분류 구현 계획

> 이번 구현의 목표는 기능 추가 자체가 아니라 **유지보수**다. 상세 기준·분류 배치는 [01_설계.md 5.7](./01_설계.md#57-프로젝트-상세의-관심사-분류)을 원본으로 삼는다. 이 문서는 기존 02_구현계획.md의 작성 원칙에 따라 작업 순서만 기록한다.

## 구현 순서

1. 공통 분류 설정을 추가하고 그 설정에서 Section 분류 타입을 파생한다. 기존 TypeScript 모듈과 주석 컨벤션을 따른다.
2. 설계의 분류 배치에 맞춰 네 프로젝트 JSON에 category만 추가한다. 기존 원문과 식별자는 보존한다.
3. 순수 그룹화 함수를 작성한다. 데이터 오류가 숨겨지지 않는지와 입력을 변경하지 않는지 검증한다.
4. 프로젝트 도메인의 그룹 컴포넌트를 추가하고 기존 Section 컴포넌트를 재사용한다.
5. 상세 페이지를 그룹 렌더링으로 연결한다. 기존 갤러리·증거·앵커 연결을 확인한다.
6. lint·타입 검사·production build를 실행한다. 네 상세 페이지의 분류 순서·빈 분류 생략·본문 보존·반응형·테마·증거·직접 문단 이동을 검증한다.
7. 구현/검증 보고서에 실제 수정 범위, 실행 결과와 확인하지 못한 범위를 구분해 기록한다.
