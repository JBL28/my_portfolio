### Home Server

미니 PC에 Linux 기반 서버 환경을 구축하고 직접 운영하는 개인 인프라 프로젝트

**개발 기준을 운영 환경까지 넓히다**

2026.01 ~ 현재 · 개인 프로젝트  
Infrastructure · DevOps

**주요 기여**  
접근 경계 설계 · 서비스 운영 · 모니터링 · 운영 자동화

- 서비스 공개 필요 여부에 따라 접근 경계를 분리
  - 내부 서비스 → Tailscale
  - 공개 서비스 → Cloudflare Tunnel + Nginx
- Docker Published Port의 실제 외부 노출을 확인
  - Public 노출 제거 후 Docker Network와 Nginx를 통해서만 접근하도록 변경
- 모니터링으로 서버 이상 여부를 배제하고 VPN 접근 경로에서 장애 원인 특정
  - Tailscale Node Key 만료 확인 후 갱신 자동화
- 개인 서버의 GitLab Runner·SonarQube 환경을 팀 프로젝트 CI/CD에 재활용

**Result**  
개인 운영 환경에서 검증한 CI/CD·품질 관리 환경을 팀 프로젝트에 재사용

**Tech Stack**  
Linux · Docker · Nginx · Tailscale · Cloudflare · Grafana

→ **개인 운영 경험을 팀의 개발 환경으로**

### DailyBand

초보자가 AI 피드백을 받으며 온라인으로 합주할 수 있는 실시간 음악 서비스

**불확실성과 AI까지 포함한 개발 흐름을 다시 통제하다**

2026.07 ~ 2026.08 · 팀 프로젝트  
Backend · Infrastructure · CI/CD · Architecture

**주요 기여**  
컴포넌트 간 계약 복구 · Storage/AI 작업 구조 설계 · CI 품질 기준 구축

- BE·FE·AI·Signaling 사이에서 무너진 API 계약을 역분석하고 다시 정의
  - AI Agent로 탐색 속도를 높이고 사람의 검수와 Mock Server로 결과 검증
- BE / Storage / AI Worker의 책임 경계를 분리
  - Presigned URL 기반 직접 업로드와 Backend 중심의 상태 관리 구조 설계
- 직접 업로드 이후 SHA-256·크기·Content-Type을 검증해 파일 신뢰 공백 보완
- DB Transaction 외부에서 동작하는 AI Worker의 실패를 고려해 Job 복구 구조 설계
- AI Agent가 생성한 코드에도 기존 코드와 동일한 CI Quality Gate 적용
  - 기준 미달 변경사항의 배포 진입 차단
- 실시간 오디오 레이턴시를 I/O · Network · Buffer로 분해
  - 팀이 제어 가능한 지연에 집중해 WebRTC에서 AOO/JUCE 기반 구조로 전환

**Result**  
BE · FE · AI · Signaling 간 통합 기준을 복구하고 최종 통합 환경 구성

**Tech Stack**  
Spring Boot · PostgreSQL · Redis · MinIO · GitLab CI · SonarQube · AOO · JUCE

→ **AI를 활용하면서도 계약·경계·검증으로 결과를 통제**

## 03. How I Work

### 기준

### 경계

컴포넌트가 무엇을 책임하고 무엇을 책임지지 않는지 구분합니다.

Home Server의 Public / Private 경계에서

### 검증

DB 장애 주입 → 외부 접근 경로 확인 → 파일 무결성 검증 → CI Quality Gate
